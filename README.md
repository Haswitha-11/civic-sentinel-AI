🚀 Civic Sentinel AI

AI-Powered Public Grievance Management System

An intelligent and multilingual platform that simplifies public grievance management using Artificial Intelligence.

📌 Project Overview

Civic Sentinel AI is an AI-powered web application designed to improve the traditional public grievance management process. It automates complaint analysis, department classification, sentiment detection, urgency prediction, and complaint summarization.

The platform provides two dedicated portals: a Citizen Portal for submitting and tracking grievances, and an Administrator Dashboard for managing complaints efficiently.

It supports four languages — English, Kannada, Hindi, and Telugu — making the platform accessible to a wider range of citizens.

🎯 Objectives

- Automate grievance classification using Artificial Intelligence.
- Support multilingual complaint submission.
- Analyze citizen sentiment and predict complaint urgency.
- Identify the appropriate government department.
- Generate AI-powered complaint summaries.
- Detect duplicate or similar complaints.
- Provide secure citizen and administrator portals.
- Improve transparency and reduce manual administrative workload.

✨ Key Features

- Multilingual Support: English, Kannada, Hindi, and Telugu.
- AI-Based Classification: Automatically identifies the appropriate department.
- Sentiment Analysis: Understands the emotional tone of complaints.
- Urgency Prediction: Categorizes grievances as High, Medium, or Low priority.
- AI Summarization: Generates concise complaint summaries.
- Duplicate Detection: Identifies similar or repeated grievances.
- Citizen Portal: Supports complaint submission and status tracking.
- Admin Dashboard: Enables centralized grievance management.
- File Attachments: Allows supporting images and documents.
- Real-Time Updates: Provides complaint status notifications.

⚙️ Installation and Setup

Prerequisites: Node.js, npm, Supabase account, and Google Gemini API access.

Step 1: Clone the repository

git clone https://github.com/Haswitha-11/civic-sentinel-Al.git

Step 2: Navigate to the project

cd civic-sentinel-Al

Step 3: Install dependencies

npm install

Step 4: Configure environment variables

Create a local ".env" file with the required Supabase and Gemini configuration. Never upload secret credentials to GitHub.

Step 5: Run the application

npm run dev

Open the local URL displayed in your terminal.
